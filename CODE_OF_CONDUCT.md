# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. In short: be welcoming, respectful and constructive; harassment and
personal attacks are not tolerated in issues, pull requests or any other project space.

## Reporting

Report unacceptable behaviour to the maintainer at [CONTACT — AUTHOR TO FILL]. Reports are
handled confidentially. The maintainer will review each report and respond with the actions
described in the Contributor Covenant's enforcement guidelines (correction, warning, temporary
or permanent ban).
